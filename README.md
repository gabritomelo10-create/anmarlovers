# AnMar Lovers · Brandbook interativo

Apresentação interativa da marca AnMar Lovers, montada a partir do kit de marca no Google Drive
(pranchas do brandbook, Guia Social Media, Guia de entrega e produção, LEIA-ME e manifesto do kit).

## Como abrir

Página estática, sem build. Abra `index.html` no navegador, ou sirva a pasta:

```sh
npx serve .
```

Para publicar no GitHub Pages: Settings → Pages → Deploy from branch → pasta raiz.

## Conteúdo

1. Essência · 2. Logo e símbolo (fundo/cor com verificação de contraste) · 3. Cores (copiar HEX, RGB, CMYK, combinações)
4. Tipografia (teste de frase) · 5. Pattern (gerado do símbolo oficial) · 6. Iconografia · 7. Instagram (destaques clicáveis)
8. Voz da marca · 9. Pilares e semana de conteúdo · 10. Roteiros de stories e área segura · 11. Catálogo de peças · 12. Checklist

## Ativos

`assets/logo` e `assets/icones` são cópias exatas dos SVGs em `VETORIZADOS` do Drive. O `index.html` usa os mesmos
desenhos embutidos como sprite SVG (`currentColor`), então funciona offline, exceto as fontes do Google Fonts.
